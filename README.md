# 🔐 Gerador de Senhas em Python

Projeto desenvolvido em Python com o objetivo de gerar senhas aleatórias e seguras por meio do terminal.

Este projeto faz parte dos meus estudos em programação, aplicando os conhecimentos adquiridos no **Curso de Python do Curso em Vídeo**, ministrado por Gustavo Guanabara.

## 🚀 Funcionalidades

- Geração de senhas aleatórias.
- Definição da quantidade de caracteres.
- Utilização de letras maiúsculas e minúsculas.
- Inclusão de números e caracteres especiais.
- Execução diretamente pelo terminal.

**Em desenvolvimento:**
- Personalização dos tipos de caracteres.
- Validação das entradas do usuário.
- Melhorias na interface com cores ANSI.

## 🛠️ Tecnologias utilizadas

- Python 3
- Módulo `secrets`
- Módulo `string`
- Visual Studio Code
- Git e GitHub

## 💻 Como executar

1. Clone o repositório:

   `git clone https://github.com/brunocosst/gerador-de-senhas-python.git`

2. Acesse a pasta do projeto:

   `cd gerador-de-senhas-python`

3. Execute o programa:

   `python3 main.py`

Não é necessário instalar bibliotecas externas.

## 📚 Objetivo do projeto

Praticar conceitos fundamentais da linguagem Python, como variáveis, entrada e saída de dados, manipulação de strings, importação de módulos e geração segura de valores aleatórios.
